#HexSoftwares_EDA_Titanic
Exploratory Data Analysis on Titanic Dataset for HexSoftwares Data science Intership


**Tasks Completed:**
Data cleaning + missing value handling with Pandas
Statistical analysis using Numpy & Pandas
Data visualization with Matplotlib & Seaborn
key pattern identification and insights

**Dataset:**Titanic passenger data from kaggle

**key insights:**
survival rate was only 38.4%
Gender was the strongest factor: 74% of females survived vs 19% of males
passengers in 1st class had higher survival rates
**Tools & Libraries:** python, pandas,Numpy, Matplotlib,Seaborn, Jupyter Notebook

** How to run:**
clone repo:'git clone https://github.com/fortunatekatekani/HexSoftwares_EDA_Titanic'
Install requirements:'pip install -r requirements.txt'
open notebook:'jupyter notebook notebook/EDA_Titanic.ipynb'
